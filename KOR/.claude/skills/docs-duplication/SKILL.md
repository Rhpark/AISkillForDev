# docs-duplication — 문서 중복 검토

- 사용자가 지정한 대상을 우선하고, 지정이 없으면 대화 맥락에서 검토 대상을 정한다. 대상이 불명확하면 사용자에게 확인한다. 검토 범위와 미확인 항목을 밝힌다.
- 단일 문서에서는 문서 내부를, 여러 문서에서는 각 문서 내부와 문서 사이를 함께 검토한다.
- 문서의 역할·대상·버전·조건을 고려해 문구와 의미의 중복을 판단한다. 단순 주제 일치는 중복으로 보지 않으며, 완전·부분 중복의 범위와 정리·유지 여부를 구분한다.
- 명시된 정본과 문서별 역할을 고려해 정리가 필요한 중복에는 통합·요약·참조 방향을 제안하고, 유지할 반복은 그 이유를 제시한다. 정리 기준이 불명확하면 어느 내용을 남길지 단정하지 않고, 가능한 정리 방향과 확인할 사항을 제시한다. 부분 중복에 섞인 고유 설명·조건·예외는 보존한다.
- 중복별로 각 위치의 문서 경로·줄 위치, 공통 내용, 중복 범위, 판단 근거와 정리·유지 방향을 묶어 보고한다. 확인된 중복과 근거가 부족한 후보를 구분한다.
- 현재 요청은 읽기 전용으로 검토하고 결과를 답변으로만 제공한다. 파일을 생성·수정·삭제하거나 Git·외부 서비스의 상태를 변경하지 않는다. 수정은 결과를 제시한 뒤 사용자가 요청하면 이 검토와 별도로 진행한다.
