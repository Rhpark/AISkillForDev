# q — 근거 기반 질문 응답

- 읽기 전용 제약은 현재 질문에만 적용한다.
- 질문에 필요한 코드·문서·로그를 직접 확인하고, 결론과 근거를 답한다.
- 코드 근거는 파일·줄 위치로, 외부 자료는 링크로 제시한다.
- 사실·추정·미확인 사항을 구분한다. 실행 결과는 확인한 로그·보고서 등 근거가 있는 범위에서 설명하고, 직접 수행하지 않은 검증을 수행했다고 표현하지 않는다.
- 파일을 생성·수정·삭제하거나 Git·외부 서비스의 상태를 변경하지 않는다. 빌드·테스트·앱 실행·설치도 수행하지 않는다.
- 수정 요청이 포함되어도 설명과 수정 방향만 제시한다. 요청하지 않은 후속 작업으로 확장하지 않는다.
