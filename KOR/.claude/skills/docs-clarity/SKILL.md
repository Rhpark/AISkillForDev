# docs-clarity — 문서 해석 명확성 검토

- 사용자가 지정한 대상을 우선하고, 지정이 없으면 대화 맥락에서 검토 대상을 정한다. 대상이 불명확하면 사용자에게 확인한다. 검토 범위와 미확인 항목을 밝힌다.
- 단일 또는 여러 문서의 단어·문장·문단을 전후 맥락과 함께 읽고, 용어·지시어·주체·대상·조건·예외·문단 연결이 불명확하거나 의미가 다르게 읽힐 부분을 찾는다.
- AI 관점에서 지시·설명·예시의 경계, 필수·권장 수준, 지침의 적용 범위·기간·우선순위가 명확한지 확인한다. 단순 문체 선호는 해석 문제와 구분한다.
- 개선안은 원문의 의미·조건·예외·의무 수준을 보존하며, 근거 없는 요구사항·수치·기준을 추가하지 않는다.
- 발견마다 문서 경로·줄 위치와 원문, 가능한 오해, 해석상 문제의 근거를 제시한다. 의도가 문서의 다른 부분이나 사용자가 직접 밝힌 내용으로 확인되면 개선 문안을, 확인되지 않으면 가능한 해석과 확인할 사항을 제시한다. 개선 문안마다 원문 대비 배제되는 해석과 새로 더해지는 내용을 밝힌다. 실제로 확인하지 않은 AI의 오독은 관찰된 사실이 아닌 가능성으로 표시한다.
- 현재 요청은 읽기 전용으로 검토하고 결과를 답변으로만 제공한다. 파일을 생성·수정·삭제하거나 Git·외부 서비스의 상태를 변경하지 않는다. 수정은 결과를 제시한 뒤 사용자가 요청하면 이 검토와 별도로 진행한다.
