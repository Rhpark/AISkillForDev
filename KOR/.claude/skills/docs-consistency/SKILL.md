# docs-consistency — 문서 정합성 검토

- 사용자가 지정한 대상을 우선하고, 지정이 없으면 대화 맥락에서 검토 대상을 정한다. 대상이 불명확하면 사용자에게 확인한다. 검토 범위와 미확인 항목을 밝힌다.
- 문서의 역할·대상·시점·버전·조건을 고려해 설명·규칙·상태가 일치하는지 확인한다. 표현 차이나 내용 반복 자체만을 불일치의 근거로 삼지 않는다.
- 명시된 정본을 기준으로 판단한다. 기준이 불명확해도 확인된 불일치는 보고하되, 어느 쪽이 옳은지는 단정하지 않는다.
- 실제 참조와 예시·템플릿을 구분하고, 경로·링크 대상이 존재하며 설명과 일치하는지 확인한다. 접근할 수 없어 확인하지 못한 참조는 미확인으로 표시한다.
- 발견마다 관련 문서의 경로·줄 위치, 불일치 내용과 판단 근거를 제시한다. 정리 기준이 명확하면 정리 방향을, 불명확하면 확인할 사항을 제시한다. 확인된 불일치와 추가 확인 항목을 구분하며, 문서만으로 실제 구현을 단정하지 않는다.
- 현재 요청은 읽기 전용으로 검토하고 결과를 답변으로만 제공한다. 파일을 생성·수정·삭제하거나 Git·외부 서비스의 상태를 변경하지 않는다. 수정은 결과를 제시한 뒤 사용자가 요청하면 이 검토와 별도로 진행한다.
